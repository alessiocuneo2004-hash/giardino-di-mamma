# 🌷 Giardino di Mamma

Un gioco di blocchi che cadono, a tema giardino: sistema le aiuole e completa le file per farle fiorire.

## Giocare

- **Al computer:** apri `index.html` con un doppio clic.
- **Sul telefono:** apri il link del gioco nel browser e installalo come app:
  - **Android (Chrome):** menu ⋮ → *Aggiungi a schermata Home* / *Installa app*.
  - **iPhone (Safari):** pulsante Condividi → *Aggiungi alla schermata Home*.

Dopo la prima apertura funziona anche senza internet.

## Comandi

- Tastiera: ← → sposta · ↑ ruota · ↓ scende · Spazio lascia cadere · P pausa
- Telefono: i pulsanti grandi sotto il campo di gioco

Ogni velocità (Tranquilla, Normale, Veloce) ha il suo record, salvato sul dispositivo.
